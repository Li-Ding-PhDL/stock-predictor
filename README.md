「取数 → 特征 → 训练 → 评估 → 可视化」流水线，把 **35 种算法**插拔在一起，

## ✨ 核心特性

### 🎯 诚实优先，绝不自欺
- **默认预测"涨跌幅"而非"价格"**：预测价格会让 R² 虚高到 0.9+（因为"明天价≈今天价"），是假象；预测涨跌幅更平稳、更诚实。
- **两条强制基准**：`Naive(前值)`（价格误差参照）+ `总是涨(方向基准)`（DA=历史上涨日占比）。模型必须明显超过它们才算有用。
- **方向准确率 DA + 上涨精确率 UP_P**：比 R² 更能反映"能不能真赚钱"。
- **DA 二项显著性检验**：DA=53% 到底是真本事还是运气？给出 p 值，样本太少直接标"可能只是运气"。
- **多重比较偏差警示**：比了一堆模型再挑最好的，本身就偏乐观——软件会提醒你去做样本外验证。
- **预测有置信区间**：未来预测给约 80% 置信带（点预测必错，区间才诚实）。

### 🧠 35 种算法 + 5 种超参优化
- 传统/集成：SVR、LSSVM、GPR、Lasso、Ridge、ElasticNet、PLSR、KNN、RF、ExtraTrees、Bagging、AdaBoost、GBRT、XGBoost、LightGBM、CatBoost、决策树…
- 深度学习：LSTM、GRU、Transformer、TabNet、CNN、DNN、ResNet、BPNet、RBFNet
- 公式演化：符号回归 SR、GEP、MEP
- 经典时序：ARIMA
- 超参优化：PSO / GA / FA / SOA / **BO(贝叶斯，默认)**
- 缺少可选依赖（xgboost/torch/gplearn 等）会**自动降级、不崩溃**，界面对应算法置灰并注明缺哪个库。

### 📈 未来一周·逐日预测
对**下 1~5 个交易日（约下周一~周五）各自独立训练一个"直接预测第 h 天"的模型**，
得到每天的预测价 + 涨跌 + 约 80% 置信区间。**不做递归预测**（拿预测喂预测会误差爆炸），**不编造未来的开高低量**。
日期取自**真实交易日历**，自动跳过周末与法定节假日。

### 💰 贴合 A 股制度的收益回测
「预测涨就满仓、预测跌就空仓」走一遍历史，扣手续费，和"买入持有"及"沪深300大盘"对比净值：
- **T+1**（持有≥1日天然满足）、**涨停买不进 / 跌停卖不出 / 停牌不可交易**（按板块自动涨跌停幅度：主板10%、创业板/科创板20%、北交所30%、ST 5%）
- **风控**：波动率目标仓位（高波动自动减仓）、单段止损
- 输出：年化、最大回撤、胜率、夏普（扣无风险利率）、相对大盘超额
> 只有**明显跑赢买入持有和大盘**，才说明预测涨跌真的能赚钱。

### 🏆 因子打分选股（横截面，5+1 因子）
价值（低 PE/PB）+ 动量（近 3 月）+ 资金（主力净流入）+ **质量（ROE/营收增速）** + **低波动** + **技术面综合分（RSI/KDJ/MACD/尾盘强弱）**，
百分位排名加权、扣风险惩罚后排序。**这是研究筛查工具，不是荐股**；排在前面 ≠ 该买。

### 📉 尾盘五维选股（新增，含历史有效性验证）
基于「五维尾盘法」量化筛选：①涨幅 3-5%  ②换手率 5-20%  ③流通市值 50-500 亿  ④量比>1 且连续 3 日放量  ⑤均线多头排列。
建议 **14:30 后**操作，结果含**五维雷达图 + 涨幅/换手率散点图**可视化；数据源缺字段（如换手率）时如实标注"实际按几维评分"，不当"条件不满足"处理。
**「历史有效性验证」**：`tail_market_scan_backtest()` 逐日回放五维条件、配对未来 N 日真实收益，检验"满足条件数越多、未来收益是否真的越好"，用 DA 二项检验判断高分组胜率是否显著——纯规则打分默认未经验证，这一步补上。

### 💼 仓位管理工具（新增）
**1% 风险逆推计算器**：公式 = 总资产 × 风险比例 ÷ 止损幅度，自动取整百股；
**金字塔建仓可视化**：30% 底仓 + 40% 加仓 + 30% 追涨，永远保留 10-20% 现金底线，配套 Matplotlib 动态图。

### 📊 大宗交易分析（新增）
历史大宗交易明细（折溢率/成交额/买卖方营业部）。**折溢率仅作客观数值展示/特征，不下"机构看多/看空"因果结论**——
A 股大宗交易折价是流动性补偿导致的结构性常态（历史主流折价幅度常年在 5%~8%），
常见驱动是股权激励解禁减持、员工持股退出、大股东内部转让等，多数与"看空"无关；
同时自动接入训练特征（`bt_premium_5d`/`bt_amount_5d` 等），通过 `merge_asof(backward)` 无未来泄露。

### 🔍 监管披露观察名单（新增）
监控大宗交易折溢率（`bt_premium_5d`）、大股东/高管近5日净增减持（`hc_net_shares_5d`）、
龙虎榜近5日机构净买额（`lhb_net_amount_5d`，可选）三项监管强制披露信号，触发条件满足任一即入观察名单，
并与模型独立给出的方向预测做交叉验证（一致更值得关注，冲突更应谨慎）。
配套 `regulatory_watchlist_backtest()` 做**历史有效性验证**（同尾盘选股一样，不假定"条件越多越好"，用 DA 显著性检验说话）。
增减持/上榜原因五花八门（股权激励行权、员工持股退出、内部转让等），**不下看多看空因果结论**，需人工核实公告性质。

### 🎲 方向概率输出原型 + 校准检验（新增，实验性）
`estimate_direction_probability()`：复用模型在独立验证集上的预测残差经验分布（非假设正态，A 股收益率肥尾），
反推"下一期上涨"的概率估计。**明确标注未经校准检验**——`calibration_check()` 用已验证的历史预测按声称概率分桶，
比较"平均声称概率" vs "真实上涨占比"，样本不足 20 条时如实返回"数据不足"，不早下结论；
每个分桶再做**二项显著性检验**（H0：真实概率=声称概率）+ **多重比较校验**（`multiple_comparison_correct()`，
与"多模型选优"共用同一套 Bonferroni/BH-FDR 方法），分桶越多越容易凑出"看起来偏差很大"的桶，不校验不下结论。

### 🧮 会计学盈余质量预警 + 有效税率异常筛查（新增）
复用财报指标同一张表零额外请求：**经营现金流/净利润比**（<100% 提示净利润缺现金流支撑，"应计盈余质量"经典信号）、
**应收账款 / 存货周转天数同比**（拉长提示回款变慢/滞销积压，用同比而非环比避开季节性误判）、
**有效税率异常**（明显低于 15% 法定最低优惠档、或税率骤降但净利未同向下滑）。均为**警示信号、不下"造假/避税"结论**，
已接入因子选股的风险提示与质量因子打分。

### 📐 因子权重优化（新增，实验性）
`optimize_factor_weights()`：对价值/动量/低波动三个"有可回放历史序列"的因子做**岭回归 Ridge**，
用历史(标准化因子值 → 未来 N 日收益)拟合出数据驱动的建议权重，替代默认等权平均（Barra/Fama-French 式因子合成思路）。
资金流/质量/技术面因子因没有可回放的历史时点值（用当前值冒充历史值=用了未来信息）**不参与优化、仍手动设权**，
如实标注"样本内 R² 通常很低是正常现象"、"不保证样本外有效"，不神化为"更准的模型"。

### 📊 策略业绩归因：Beta / Jensen's Alpha（新增）
回测结果新增 CAPM 经典指标：策略收益对沪深300收益做线性回归，斜率 **Beta**（系统性风险，>1 更暴涨暴跌）、
截距（年化）**Jensen's Alpha**（扣除"光跟涨大盘"部分后，策略自己还能不能挣钱），与信息比率同属业绩归因框架。

### 💵 模拟交易账户（新增）
按 A 股真实规则的纸面模拟盘：`create_paper_account()` 建账户（指定候选股票池、算法、决策周期、初始资金），
`run_paper_account()` 逐周期用因子打分从股票池选股、跑模型信号自动买卖（真实手续费、整手交易、T+1、涨跌停/停牌限制，
不允许零股/负现金），净值曲线与"等额买入持有沪深300"强制对比。GUI 新增「模拟交易」页签。
**明确边界**：纸面模拟、不保证未来重演、不构成投资建议，盈亏自负。

### 🔎 其它
- **预测跟踪**：把预测存下来（手动记录支持 1/2/3/4/5/10/20/30/40/60 日全周期，「未来预测图」自动同步逐日 1~5 日，均标注来源），
  等目标日到了自动拉真实股价对比，区分**方向命中**（涨跌猜对）与**股价命中**（`|实际价-预测价|/实际价 ≤ 5%` 才算命中，不用置信区间衡量）两个不同维度；

本项目对照了量化研究/开发岗位常见的技术要求（数据处理、可视化、回测框架、算法统计、市场/行业知识、Linux/Docker、反数据泄漏纪律等），
逐条做了工程化落地。**这些不是"面试话术"，而是可运行、可复现的真实功能**：

| 量化 JD 技术要求 | 本项目的对应实现 |
|---|---|
| 数据处理（Pandas/Numpy） | 整条「取数→特征→训练→评估」流水线；多源容错、parquet 缓存、merge_asof 防泄漏对齐 |
| 数据可视化 | K线/预测对比/未来逐日(带置信带)/回测净值/**相关性热力图**/**因子IC柱状图**/**消融柱状图**/**宏观趋势图** 等 |
| **回测框架** | 自研 `backtest_directional`(含A股T+1/涨跌停/停牌/风控)+ **独立向量化复算 + 第三方 Backtrader 三方交叉验证**，证明回测非账面 |
| 算法/统计/机器学习 | 35 种算法 + 5 种超参优化(PSO/GA/FA/SOA/BO) + DA二项显著性 + Walk-Forward + 因子IC/ICIR |
| 市场指数/**行业划分** | 沪深300 大盘环境/regime；**行业分类 + 行业内 PE/PB 估值分位**(同业比才公平) |
| 熟悉股票交易规则 | A股涨跌停(按板块 10/20/30/ST5%)、T+1、停牌、集合竞价时段判断、真实交易日历(跳节假日) |
| **北交所代码识别** | `_is_bj_code`(4/8/9开头)只走 akshare、跳过 baostock；akshare 限流专属退避（实测 bug 修复） |
| 宏观经济分析 | **GDP/CPI/PPI/PMI/M2/LPR 趋势图**(仅研究背景，因发布滞后=前视风险，**明确不入训练特征**) |
| Linux / Bash / Docker | `Dockerfile`(命令行/定时任务镜像) + `scripts/daily_verify.sh`(cron 每日自动核对到期预测) |
| **反数据泄漏纪律** | [AGENTS.md](AGENTS.md) 第 2b 节「反数据泄漏 Checklist」10 条可勾选自查（量化最看重的工程素养） |
| Agentic Coding（AI 协作） | [AGENTS.md](AGENTS.md) 全套红线 + 反泄漏清单，本身就是给 AI/人协作的"审代码 checklist" |

> 说明：以上参考的是**量化行业公开的技术能力要求**（非任何具体公司的私有 JD 内容）；所有实现均按本项目「诚实优先、真实数据、不造假」原则完成。
